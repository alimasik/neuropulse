# claude-config/ — место для будущих slash-команд и subagents

> Эта папка — заготовка. При работе с Claude Code в локальной среде переименуйте её в `.claude/` (Cowork ограничивает запись в эту директорию).

## Что сюда положить, когда понадобится

### `commands/` — слэш-команды проекта

Примеры команд, которые имеет смысл создать на хакатоне:

| Команда | Что делает |
| --- | --- |
| `/seed-biometry` | Генерирует 1000 синтетических биометрических сессий через `data/generator.py` и заливает в SQLite |
| `/run-demo` | Запускает backend + frontend параллельно, открывает браузер |
| `/check-ux` | Проверяет компоненты frontend на соответствие `docs/ux-guidelines.md` |
| `/train-baseline` | Обучает baseline ML-модель на синтетике и сохраняет в `ml_core/models/` |
| `/screenshot-flow` | Делает скриншоты ключевых экранов для презентации |

Каждая команда = один markdown-файл с инструкцией Claude Code.

### `agents/` — специализированные subagents (опционально)

На MVP не обязательно, но если нужно:

| Агент | Зона ответственности |
| --- | --- |
| `ux-reviewer` | Сверяет UI-компоненты с `docs/ux-guidelines.md` |
| `ml-engineer` | Работа с `ml_core/`, фичеринжиниринг, тюнинг моделей |
| `data-faker` | Генерация и валидация синтетических биометрических данных |

## Шаблон для slash-команды

```markdown
---
description: Краткое описание команды (одна строка)
---

# Что сделать

Опиши задачу пошагово (2-6 шагов).

# Что прочитать перед началом

- путь/к/файлу1.md
- путь/к/файлу2.md

# Формат результата

Опиши, что должно появиться в репозитории/чате после выполнения.
```
