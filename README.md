# NeuroPulse

> **Цифровой ассистент предиктивной десенсибилизации** для людей с РАС, синдромом Туретта и другими нейроотличными состояниями.

MVP, разработанный на хакатоне (трек MedTech).

---

## Что это

Большинство существующих решений работают **реактивно** — помощь приходит уже после мелтдауна или приступа тиков. К этому моменту нервная система уже на пределе.

**NeuroPulse меняет парадигму на предиктивную**: система за 10–15 минут до приближающегося срыва видит ранние биометрические маркеры (падение HRV, рост пульса, изменение паттернов движений) и мягко предлагает интервенцию — дыхательное упражнение, "тихий маршрут" в обход шумных зон, или активирует AAC-карточки для невербальной коммуникации.

## Ключевые модули

| Модуль | Что делает |
| --- | --- |
| **Predictive Engine** | ML-модель анализирует поток биометрии и предсказывает сенсорную перегрузку |
| **Mobile UI** | Главный экран мониторинга, экран интервенции, "тихая карта", AAC-режим |
| **Sensory Map** | Карта с уровнем шума по районам и тихими маршрутами |
| **Doctor's Dashboard** | Веб-панель для врача/родителя с историей эпизодов и триггерами |

## Запуск

См. `scripts/CLAUDE.md` для актуальных команд. Кратко:

```bash
# Backend
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# Frontend
cd frontend && npm install && npm run dev
```
