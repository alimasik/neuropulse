# UX-гайдлайны NeuroPulse — тёмная тема (РАС/Туретт-friendly)

> **Этот документ — не рекомендации, а обязательные правила.** Любой UI-элемент, нарушающий пункты ниже, считается дефектом. Claude Code обязан сверяться с этим файлом перед изменением чего-либо в `frontend/`.
>
> **Версия 2 (май 2026):** Перешли с пастельной на «мягкую тёмную» тему по запросу команды.
> Тёмная тема снижает световую нагрузку — большинство РАС-исследований показывают, что
> приглушённые тёмно-синие тона снижают порог сенсорной перегрузки сильнее, чем светлые фоны.

---

## Принципы (фундамент)

1. **Сенсорная безопасность важнее визуальной эффектности.** Если «красиво» конфликтует с «безопасно для пользователя» — выбираем безопасно.
2. **Предсказуемость.** Интерфейс не должен преподносить сюрпризов: внезапных модалок, прыжков фокуса, неожиданных звуков.
3. **Минимум одновременных стимулов.** На экране — максимум один движущийся элемент за раз.
4. **Низкая яркость без потери читаемости.** Тёмно-синий фон + мягкий ice-blue текст ≈ 8 : 1 контраст (AAA WCAG).
5. **Управляемость пользователем.** Анимации, звуки, вибрации — всегда отключаемы.

---

## Цветовая палитра (тёмная)

**Используем (тёмно-синяя гамма, низкая насыщенность):**

| Назначение | HEX | Заметка |
| --- | --- | --- |
| Основной фон | `#0E1726` | Глубокий midnight, **не чёрный** — чёрный слишком контрастный для глаз |
| Поверхность карточек | `#152038` | На полтона светлее фона |
| Поднятые элементы | `#1A2740` | Для модалок, дашборд-блоков |
| Текст основной | `#E8EEF7` | Soft white, **не чисто белый** |
| Текст вторичный | `#8FA0BC` | Slate-blue, для подписей |
| Акцент «спокойствие» | `#67E8B5` | Mint — нейтральный позитивный |
| Акцент «внимание» (предиктив) | `#FFB36B` | Тёплый янтарный, **не красный** |
| Акцент «критично» (только SOS) | `#FF7B8B` | Приглушённый розовый, **не алый** |
| Брендовый акцент NeuroPulse | `#5EC8FF` | Ice blue — для логотипа, primary CTA, active links |
| Линии/границы | `#2A3550` | Едва различимые |
| Tint «спокойно» (фон карточки) | `#0F2D2A` | Зеленовато-тёмный |
| Tint «нарастает» | `#2E2418` | Янтарно-тёмный |
| Tint «критично» | `#2E1820` | Розово-тёмный |

**Категорически запрещено:**
- Чистый чёрный `#000000` — глазам тяжело отделять контент от фона.
- Чистый белый `#FFFFFF` на тёмном фоне — даёт «свечение», бьёт по фоточувствительным.
- Чистый красный `#FF0000` и неоновые оттенки.
- Резкие градиенты с переходом через светлые тона.

## Типографика

- **Шрифт:** `Manrope` (основной) + system-ui (фолбэк). Гуманистический гротеск с округлой формой — лучше распознаётся при низкоконтрастном фоне.
- **Источник:** Google Fonts (`Manrope:wght@400;500;600;700`).
- **Размер основного текста:** 16–18px (мобильный), 18–20px (десктоп).
- **Размер заголовков:** масштаб 1.25 (мажорная третья), не 1.5+.
- **Межстрочный интервал:** `line-height: 1.6` минимум.
- **Межбуквенный интервал:** обычный (0). Для CAPS-меток допустимо `letter-spacing: 0.06em`.
- **Жирность:** `400` для текста, `600`–`700` для заголовков. **Не использовать** `font-weight: 800+` (на тёмном фоне создаёт «жирные пятна»).
- **Курсив:** только для коротких акцентов, не для блоков текста.
- **ВЕРХНИЙ РЕГИСТР:** только для коротких меток (kicker над заголовком, бейджи).

---

## Размеры и хитбоксы

- Минимальный размер тапа — **48×48px**.
- Кнопки SOS и AAC — **минимум 64px высотой**.
- Расстояние между кликабельными элементами — **минимум 8px**, лучше 16px.
- Кнопки на экране интервенции — **полная ширина**.

## Анимации и переходы

| Правило | Подробности |
| --- | --- |
| Длительность | 200–400ms. |
| Easing | `ease-in-out` или кастомная плавная. **Никаких bounce, elastic, overshoot.** |
| Мигание | **Запрещено**. Никаких `infinite` анимаций кроме одной — дыхательной. |
| Параллакс | Запрещён. |
| Респект `prefers-reduced-motion` | Обязателен. Все анимации отключаются. |

### Единственная разрешённая бесконечная анимация
**Дыхательный индикатор** — плавное масштабирование круга по циклу 4-7-8 (4 с вдох / 7 с задержка / 8 с выдох). Это терапевтический паттерн, не декорация.

---

## Звук и вибрация

- Любой звук — **только по запросу пользователя**.
- Доступная палитра звуков: эмбиент, шум дождя, белый шум, brown noise. **Никаких бипов, мелодий, фанфар.**
- Вибрация — только в режиме дыхательной практики (плавная, не резкая).

## Состояния стресса в UI (тёмная тема)

UI имеет три визуальных режима по `label` от ML:

| Label | Состояние | Tint фона | Акцент | Поведение |
| --- | --- | --- | --- | --- |
| 0 | Стабильно | `#0F2D2A` (зелёный tint) | `#67E8B5` mint | Спокойный волновой индикатор |
| 1 | Нарастание | `#2E2418` (янтарный tint) | `#FFB36B` amber | Появляется CTA «Сделать перерыв» |
| 2 | Высокий риск | `#2E1820` (розовый tint) | `#FF7B8B` coral | Авто-переход на экран интервенции, увеличенный SOS |

**Переход между состояниями — всегда плавный (≥ 300ms).** Никаких внезапных вспышек.

---

## Иконки

- Стиль: outline, толщина 1.5–2px. Lucide / Feather.
- Размер: 24×24 в навигации, 32×32 в CTA, 48×48 на AAC-карточках.
- На тёмном фоне толщину делаем чуть толще (`strokeWidth: 1.8–2.0`) для лучшей различимости.

---

## AAC-карточки (экстренная коммуникация)

Особый случай — карточки должны быть **узнаваемы прохожим за 1 секунду**.
**Внимание:** на AAC-экране фон карточек делается **светлым** (`#FFFFFF`),
а не тёмным — потому что показывать тёмный экран постороннему человеку
в плохом освещении — не работает. Это исключение из общего правила.

- Большая иконка (≥ 80px) сверху.
- Один короткий текст (≤ 8 слов), крупно.
- Языки: русский + английский (toggle).
- Палитра карточки: фон `#FFFFFF`, иконка/текст `#0E1726`, рамка `#5EC8FF`.

Базовый набор (минимум 4):
1. «У меня аутизм. Я не могу говорить, но всё понимаю.»
2. «Помогите мне дойти до тихого места.»
3. «Не трогайте меня. Пожалуйста, отойдите.»
4. «Позвоните моему близкому.» (с кнопкой вызова)
