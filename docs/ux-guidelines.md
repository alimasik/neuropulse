# UX-гайдлайны NeuroPulse (РАС/Туретт-friendly)

> **Этот документ — не рекомендации, а обязательные правила.** Любой UI-элемент, нарушающий пункты ниже, считается дефектом. Claude Code обязан сверяться с этим файлом перед изменением чего-либо в `frontend/`.

---

## Принципы (фундамент)

1. **Сенсорная безопасность важнее визуальной эффектности.** Если "красиво" конфликтует с "безопасно для пользователя" — выбираем безопасно.
2. **Предсказуемость.** Интерфейс не должен преподносить сюрпризов: внезапных модалок, прыжков фокуса, неожиданных звуков.
3. **Минимум одновременных стимулов.** На экране — максимум один движущийся элемент за раз.
4. **Информация плотностью не подавляет.** Воздух между блоками — критичен.
5. **Управляемость пользователем.** Анимации, звуки, вибрации — всегда отключаемы.

---

## Цветовая палитра

**Используем (пастель, низкая насыщенность):**

| Назначение | HEX | Заметка |
| --- | --- | --- |
| Основной фон | `#F5F7F4` | Тёплый off-white, не чисто белый |
| Поверхность карточек | `#FFFFFF` | Чистый белый только для контраста |
| Текст основной | `#2F3A36` | Тёмно-графитовый, **не чёрный** (чёрный слишком контрастный) |
| Текст вторичный | `#6B7770` | Серо-зелёный |
| Акцент "спокойствие" | `#A8C8B8` | Шалфейный |
| Акцент "внимание" (предиктив) | `#E8C58F` | Тёплый янтарный — **не оранжевый и не красный** |
| Акцент "критично" (только SOS) | `#D9888F` | Приглушённый коралл, **не алый** |
| Линии/границы | `#E0E5E2` | Едва различимые |

**Категорически запрещено:**
- Чистый красный `#FF0000`, чистый зелёный `#00FF00`, неоновые оттенки.
- Высококонтрастные сочетания "чистый чёрный на чистом белом" — это стимул для гиперчувствительности.
- Градиенты с резкими переходами.

## Типографика

- **Шрифт:** Inter, system-ui (без засечек, гуманистический).
- **Размер основного текста:** 16-18px (мобильный), 18-20px (десктоп).
- **Размер заголовков:** масштаб 1.25 (мажорная третья), не 1.5+.
- **Межстрочный интервал:** `line-height: 1.6` минимум.
- **Межбуквенный интервал:** обычный. Никаких `letter-spacing: 0.2em` (даёт ощущение "разорванности").
- **Жирность:** `400` для текста, `600` для заголовков. **Не использовать** `font-weight: 900`.
- **Курсив:** избегать — труднее распознаётся.
- **ВЕРХНИЙ РЕГИСТР:** только для коротких меток (CAPS-фразы воспринимаются как крик).

---

## Размеры и хитбоксы

- Минимальный размер тапа — **48×48px** (правило Material/iOS, но критичнее для людей с тиками/тремором).
- Кнопки SOS и AAC — **минимум 64px высотой**.
- Расстояние между кликабельными элементами — **минимум 8px**, лучше 16px.
- Кнопки на экране интервенции — **полная ширина** (минимизирует промахи при треморе).

## Анимации и переходы

| Правило | Подробности |
| --- | --- |
| Длительность | 200–400ms. Не быстрее (резко), не медленнее (раздражает). |
| Easing | `ease-in-out` или кастомная плавная. **Никаких bounce, elastic, overshoot.** |
| Мигание | **Запрещено** (триггер эпилепсии и сенсорной перегрузки). Никаких `infinite` анимаций кроме одной — дыхательной (см. ниже). |
| Параллакс | Запрещён. Вызывает дезориентацию. |
| Респект `prefers-reduced-motion` | Обязателен. Все анимации отключаются. |

### Единственная разрешённая бесконечная анимация
**Дыхательный индикатор** на экране интервенции — плавное масштабирование круга по циклу 4-7-8 (4с вдох / 7с задержка / 8с выдох). Это терапевтический паттерн, не декорация.

---

## Звук и вибрация

- Любой звук — **только по запросу пользователя**. Никаких "уведомительных" по умолчанию.
- Доступная палитра звуков: эмбиент, шум дождя, белый шум, brown noise. **Никаких бипов, фанфар, мелодий.**
- Вибрация — только в режиме дыхательной практики (плавная, не резкая).

---

## Состояния стресса в UI

UI имеет три визуальных режима в зависимости от `label` от ML:

| Label | Состояние | Палитра | Поведение |
| --- | --- | --- | --- |
| 0 | Стабильно | Шалфейный (`#A8C8B8`) | Спокойный волновой индикатор |
| 1 | Нарастание | Янтарный (`#E8C58F`) | Мягкий бэкграунд-тинт, появляется CTA "Сделать перерыв" |
| 2 | Высокий риск | Коралл (`#D9888F`) | Автопереход на экран интервенции, увеличенный SOS |

**Переход между состояниями — всегда плавный (>=300ms).** Никаких внезапных красных вспышек.

---

## Иконки

- Стиль: outline, толщина 1.5–2px. Никаких filled glyphs с яркими тенями.
- Размер: 24×24 в навигации, 32×32 в CTA, 48×48 на AAC-карточках.
- Источник: Lucide / Feather. Стилистическое единство — выше эстетики.

---

## AAC-карточки (экстренная коммуникация)

Особый случай — карточки должны быть **узнаваемы прохожим за 1 секунду**.

- Большая иконка (≥80px) сверху.
- Один короткий текст (≤8 слов), крупно.
- Языки: русский + английский (toggle).
- Контраст здесь **выше обычного** — карточку могут показывать в плохом освещении.
- Палитра: фон `#FFFFFF`, иконка/текст `#2F3A36`, рамка `#A8C8B8`.

Базовый набор (минимум 4):
1. «У меня аутизм. Я не могу говорить, но всё понимаю.»
2. «Помогите мне дойти до тихого места.»
3. «Не трогайте меня. Пожалуйста, отойдите.»
4. «Позвоните моему близкому.» (с кнопкой вызова)

## Чек-лист перед PR в frontend/

- [ ] Использованы только цвета из палитры выше.
- [ ] Все тапаемые элементы ≥48px (или 64px для SOS/AAC).
- [ ] Нет мигающих/быстрых анимаций.
- [ ] Учтён `prefers-reduced-motion`.
- [ ] Шрифт Inter, `line-height ≥ 1.6`.
- [ ] Тёмный текст — `#2F3A36`, не `#000000`.
- [ ] Состояния стресса визуализированы плавными переходами.
- [ ] Звук/вибрация только по явному действию пользователя.
