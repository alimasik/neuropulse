# Стартовый промпт для Claude Code

> Этот файл — **не** для Claude Code на исполнение. Это шпаргалка для **вас**: открываете проект в Claude Code локально, копируете один из блоков ниже в чат и отправляете. Claude Code прочитает всю архитектуру и пойдёт работать по правилам.

---

## Промпт №1 — Первый запуск (boot sequence)

Используйте, когда впервые открыли репозиторий в Claude Code.

```text
Привет. Это репозиторий хакатон-проекта NeuroPulse — цифровой ассистент предиктивной
десенсибилизации для людей с РАС и синдромом Туретта.

Прежде чем приступать к коду, выполни следующие шаги по порядку:

1. Прочитай корневой CLAUDE.md.
2. Прочитай docs/case-context.md — это продуктовый контекст. Любая фича обязана
   соответствовать описанным там пяти проблемам.
3. Прочитай docs/architecture.md и docs/data-model.md — это технические контракты.
4. Прочитай docs/ux-guidelines.md — обязательные правила доступности.
5. Прочитай локальные CLAUDE.md в backend/, frontend/, ml_core/, data/, scripts/.

После этого — НЕ начинай писать код. Сделай три вещи:

(а) Кратко перескажи мне, что ты понял про проект, в 5-7 пунктах.
(б) Назови три ключевых ограничения, которые ты будешь соблюдать.
(в) Предложи, с чего стартануть День 1 (см. секцию "Приоритеты по дням хакатона"
    в корневом CLAUDE.md).

Жди моего ответа перед тем, как создавать любые файлы.
```

## Промпт №2 — День 1: каркас и UI

Когда вы готовы начать. Запустится после подтверждения плана из Промпта №1.

```text
Поехали в День 1 — нужен работающий каркас frontend.

Задача: создай Vite+React+TypeScript+Tailwind проект в папке frontend/ и набросай
четыре главных экрана-заглушки (см. frontend/CLAUDE.md):
  - / (Главный)
  - /intervention (Интервенция)
  - /map (Sensory Map)
  - /aac (AAC-режим)

Ограничения:
- Используй только цвета из docs/ux-guidelines.md (палитра, токены в Tailwind).
- Никаких MUI/Chakra/framer-motion.
- На каждом экране пока заглушка: заголовок + один CTA. Логику не пиши.
- Респект prefers-reduced-motion на корневом уровне.

Сначала покажи план в 5 шагах, дождись ОК, потом исполняй.
```

## Промпт №3 — День 2: ML и Backend

```text
Сегодня делаем ML-ядро и FastAPI.

Часть 1 — data/:
1. Реализуй data/generator.py по спецификации в data/CLAUDE.md.
2. Создай три сценария в data/scenarios/.
3. Сгенерируй data/synthetic.csv с ~10k окон (баланс классов как в data/CLAUDE.md).

Часть 2 — ml_core/:
1. feature_extractor.py — фичи строго по docs/data-model.md (раздел "Фичи для ML").
2. train.py — RandomForest baseline, цель F1-macro >= 0.75. Сохрани
   models/baseline.joblib (НЕ .pkl).
3. model_predict.py — загрузка модели + inference, контракт из ml_core/CLAUDE.md.

Часть 3 — backend/:
1. FastAPI с эндпоинтами /ingest, /predict, /history, /feedback, /export
   (контракты в docs/data-model.md).
2. SQLite через aiosqlite + SQLAlchemy 2.x.
3. Schemas — Pydantic v2 в schemas/, ORM — в models/.
4. UserBaseline собирается из таблицы users, передаётся в ml_core.
5. /export реализует и PDF (reportlab + matplotlib для графиков), и CSV (pandas).

Ограничения:
- Никакого Docker, никакого Alembic пока, create_all на старте достаточно.
- Запрещён JWT/OAuth, user_id=1 на демо.

План в 6-8 шагах, потом исполнение.
```

## Что сделать перед первой сессией с Claude Code (вручную)

1. **Переименовать `claude-config/` в `.claude/`** (Cowork-среда блокировала запись, поэтому архитектура временно лежит в `claude-config/`). Локально проблем нет:
   ```bash
   mv claude-config .claude
   ```
2. Создать пустые папки, чтобы они существовали для будущих файлов:
   ```bash
   mkdir -p frontend backend ml_core ml_core/models data data/scenarios scripts
   ```
3. Добавить минимальный `.gitignore`:
   ```text
   node_modules/
   .venv/
   __pycache__/
   *.db
   .env
   dist/
   ```
4. Открыть Claude Code в корне проекта, отправить Промпт №1.

После этого — действуйте по дням хакатона из корневого CLAUDE.md.
