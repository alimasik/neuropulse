# scripts/ — утилиты запуска и операционные команды

> Эта папка — для скриптов, которые человек запускает руками. Никакой бизнес-логики здесь нет.

---

## Что должно появиться

```text
scripts/
├── dev.sh / dev.bat         # Запуск backend + frontend параллельно
├── seed_db.py               # Заполняет SQLite демо-сессиями
├── train_model.sh           # Шорткат для ml_core/train.py
├── demo_run.py              # Эмулирует поток биометрии в backend по сценарию
└── make_screenshots.py      # (опционально) скриншоты для презентации
```

---

## Принципы

1. **Каждый скрипт работает из корня репо.** Запускается как `bash scripts/dev.sh`, не `cd scripts && ...`.
2. **Имена в snake_case.** Расширение `.sh` для bash, `.py` для python, `.bat` только если реально нужно для Windows-команды.
3. **Один скрипт — одна задача.** Не делай "универсальный" `manage.py` с 15 командами.
4. **Печатай, что делаешь.** Скрипт должен говорить пользователю на каждом шаге: "Запускаю backend... ОК", "Обучаю модель... готово".

---

## demo_run.py (важный для питча)

Этот скрипт — главное оружие на демо. Он:

1. Читает сценарий из `data/scenarios/metro_rush.json`.
2. Запускает поток вызовов `POST /ingest` + `POST /predict` к локальному backend, имитируя реальное устройство.
3. Между вызовами делает паузы, чтобы зритель видел, как меняется состояние на frontend.

```text
python scripts/demo_run.py --scenario metro_rush --speed 10x
```

`--speed 10x` ускоряет реальное время (30 минут → 3 минуты для питча).
